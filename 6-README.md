# Yashmi Adani personal site

An editorial, mixed-media portfolio with a no-code-in-use content editor.

## Preview
Open `index.html` in a browser. Use `editor.html` to change copy, links, projects and notebook entries. Save stores the changes in that browser. Export/Import moves a content backup between browsers.

## Put it online
Upload this folder to Netlify Drop for the lowest-friction preview. For a lasting site with automatic updates, connect the folder to a GitHub repo and deploy it on Netlify or Vercel. A custom domain can be attached later.

## Important
Replace placeholder work, email and social links before publishing. The current editor is intentionally simple and private to the browser. For edits that persist for every visitor without redeploying, add a hosted CMS such as Sanity, Notion-backed Super, or Netlify Visual Editor.
